💻 Requirements

To run the Python programs, make sure Python is installed on your system.

Check your Python version:

python --version


or:

python3 --version

▶️ Running a Python File

Clone the repository:

git clone <your-repository-url>


Navigate into the project:

cd python-class-notes


Run a Python file:

python filename.py
